# Chrome Extension: AI Writing Style Consistency Checker

A Chrome extension that enforces writing style consistency across documents, emails, and web apps using configurable style guides. Detects passive voice overuse, inconsistent terminology, brand voice violations, readability score drops below threshold, and prohibited word lists. Works natively inside Gmail, Google Docs, Notion, and any content editable field. Teams can share style rule sets via a JSON config URL for brand-wide consistency.

## Installation

### Chrome
1. Download and extract the ZIP
2. Go to `chrome://extensions/`
3. Enable "Developer mode"
4. Click "Load unpacked" and select the extracted folder

### Firefox
1. Download the Firefox version
2. Go to `about:debugging`
3. Click "Load Temporary Add-on"
